# EngageWatch: student engagement classifier

FastAPI service and dashboard that classifies a webcam frame of a student into six engagement
states, accepts bulk uploads of new labelled images and retrains the model on demand.

Source code: https://github.com/jagonzibwa/Joshua-Agonzibwa-Summative-assignment---MLOP
